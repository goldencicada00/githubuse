# 如何將整個專案放入私有的github網頁上
1. `cd "C:\Users\yuhsu\OneDrive\桌面\pycmopen _git"`

2. 
    ```
    git config --global user.name  "goldencicada00"
    git config --global user.email "#你的Mail"
    git init        # 把這個資料夾變成 git repository
    git add .       # 把所有檔案加入暫存區（stage）
    ```

    檢查一下狀態：
    ```
    git status      # 會看到一堆檔案在「Changes to be committed」底下（綠色）
    ```
    
    建立第一次 commit:
    ```
    git commit -m "Initial commit"
    ```
3. 把本地端 repo 跟 GitHub 上的 repo 連起來
   * 在 GitHub 頁面上可以看到 HTTPS 的網址，大概是：`https://github.com/goldencicada00/pycmopen_SA_BRL_DRQN.git`
     在命令提示字元裡加上遠端：
     ```
     git remote add origin https://github.com/goldencicada00/pycmopen_SA_BRL_DRQN.git
     ```
   * 確認是否加成功：
     ```
     git remote -v
     ```
   * 會看到：
     ```
     origin  https://github.com/goldencicada00/pycmopen_SA_BRL_DRQN.git (fetch)
     origin  https://github.com/goldencicada00/pycmopen_SA_BRL_DRQN.git (push)
     ```
4. 把 commit 推到 GitHub
   ```
   git push -u origin main
   ```
